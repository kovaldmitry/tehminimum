# Техминимум ГМК

Офлайн-приложение для самоподготовки: автоматика, данные и ИИ на горно-металлургическом производстве; ступень 4 — «Норникель вглубь».

Открыть: https://kovaldmitry.github.io/tehminimum/ → в Safari «Поделиться» → «На экран „Домой“». После первого открытия с интернетом работает в авиарежиме.
